# Book SOP: Evidence Pack Archival & Publishing

All manuscript sections submitted for Gate 2 review must have an accompanying Evidence Pack archived for full auditability.

---

## 1. Archival Location
Save each completed Evidence Pack at:
`archives/evidence_packs/<TAG>_evidence_pack.md`
- *Example*: `archives/evidence_packs/CH02_SEC01_evidence_pack.md`

## 2. Retention Policy
- Evidence packs are immutable records of editorial acceptance. Once committed to git with a `docs(freeze)` commit, they must never be edited retroactively.
- If a section is refactored in a later edition or wave, a new Evidence Pack must be created citing the previous tag as its baseline.
